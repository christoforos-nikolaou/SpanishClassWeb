## 1. Verbos de alta rentabilidad

Sustituyen a los verbos comodín (*hacer, tener, decir, mostrar, ayudar, cambiar…*). Regla: no repetir el mismo verbo básico más de dos veces en un texto.

| Verbo básico | Alternativas más precisas |
|---|---|
| hacer | realizar, llevar a cabo, efectuar, elaborar, desarrollar |
| tener | disponer de, contar con, presentar, poseer |
| decir | afirmar, señalar, sostener, subrayar, manifestar, apuntar |
| mostrar | reflejar, evidenciar, revelar, poner de manifiesto, ilustrar |
| ayudar | favorecer, contribuir a, facilitar, fomentar, impulsar |
| cambiar | modificar, transformar, experimentar un cambio, evolucionar |
| usar | emplear, recurrir a, hacer uso de, servirse de |
| dar | ofrecer, brindar, proporcionar, aportar |
| pensar | considerar, estimar, opinar, juzgar |
| ser importante | resultar fundamental / esencial / determinante / crucial |
| problema | cuestión, dificultad, inconveniente, carencia, desafío |
| mucho / muy | considerablemente, notablemente, en gran medida, sumamente |

## 2. Colocaciones por tema

Combinaciones naturales de sustantivo + verbo o adjetivo. Aprenderlas en bloque, no palabra por palabra.

| Tema | Colocaciones |
|---|---|
| Ocio y sociedad | ocupar el tiempo libre, fomentar hábitos saludables, ocio digital, convivencia vecinal, dependencia tecnológica, brecha generacional |
| Argumentación | plantear una cuestión, aportar un argumento, refutar una idea, extraer una conclusión, cobrar relevancia |
| Gestión pública | destinar fondos, dotar de infraestructuras, revitalizar un espacio, atender una demanda ciudadana |
| Consumo | tarifa, cuota, incremento, cláusula, permanencia, reclamación formal, incumplimiento contractual |

## 3. Descripción y análisis de datos (gráficos y encuestas)

Esquema: **dato principal → comparación → dato llamativo → interpretación → opinión matizada**.

| Función | Expresiones |
|---|---|
| Introducir el gráfico | El gráfico refleja / recoge / ilustra / pone de manifiesto… |
| Primer puesto | encabezar la lista, ocupar el primer lugar, situarse a la cabeza, predominar |
| Cantidades | la mayoría, una minoría, algo más de la mitad, en torno al 50 %, apenas el 12 %, tan solo, uno de cada tres |
| Comparar | mientras que, frente a, a diferencia de, en contraste con, superar a, quedar por debajo de |
| Evolución | aumentar, incrementarse, descender, experimentar un repunte, mantenerse estable, dispararse, desplomarse |
| Agrupar categorías | En cuanto a… / Por lo que respecta a… / Respecto a… / En el ámbito de… |
| Interpretar | Cabe interpretar que… / Esto sugiere que… / De los datos se desprende que… / Estas cifras invitan a pensar que… |
| Matizar la causa | Es probable que + subj. / Podría deberse a… / Tal vez se explique por… |

## 4. Conectores por función

| Función | Conectores | Nota gramatical |
|---|---|---|
| Orden | en primer lugar, por una parte… por otra, a continuación, por último |  |
| Adición | además, asimismo, a ello se suma que, por añadidura, no solo… sino también | No repetir *además* |
| Contraste | sin embargo, no obstante, en cambio, por el contrario, a pesar de, pese a que | *pese a que* + indicativo o subjuntivo según el sentido |
| Concesión | aunque, si bien, por más que, a pesar de que | *aunque / por más que* + subj. si es hipotético; *si bien* + indic. |
| Causa | dado que, puesto que, ya que, debido a, a raíz de, gracias a | *debido a* + sustantivo; *debido a que* + verbo |
| Consecuencia | por consiguiente, por tanto, de ahí que, así pues, lo que conlleva | *de ahí que* + **subjuntivo** |
| Finalidad | con el fin de, a fin de que, con vistas a, para que | *a fin de que / para que* + subjuntivo |
| Condición | siempre que, siempre y cuando, a menos que, en caso de que | + subjuntivo |
| Ejemplo | por ejemplo, a modo de ejemplo, tal es el caso de |  |
| Reformular | es decir, dicho de otro modo, en otras palabras |  |
| Concluir | en definitiva, en suma, en síntesis, a modo de conclusión |  |

## 5. Español formal: cartas y reclamaciones

| Parte | Fórmulas |
|---|---|
| Encabezado | **Lugar y fecha** (siempre); *Estimados señores:* / *Muy señores míos:* / *Estimado Sr. / Estimada Sra.:* |
| Apertura | Me dirijo a ustedes con motivo de… / en relación con… / con el fin de exponerles… |
| Queja | manifestar mi disconformidad, expresar mi malestar, resulta inaceptable, considero injustificable, constituye un incumplimiento |
| Propuesta | propongo, sugiero, cabría plantear, resultaría conveniente, sería recomendable |
| Petición | Les solicito que + subj., Les ruego que + subj., Agradecería que + imperfecto de subj. |
| Petición precisa | … en un plazo máximo de diez días, … y que me lo confirmen por escrito |
| Advertencia | De lo contrario, … / En caso contrario, … / No dudaré en recurrir a… |
| Cierre | Les agradezco de antemano su atención / Quedo a la espera de su respuesta |
| Despedida | Atentamente, / Reciban un cordial saludo, + nombre y apellidos completos |

## 6. Estructuras sintácticas para subir a C1

| Estructura | Ejemplo |
|---|---|
| Concesiva con *si bien / aunque* | Si bien reunirse con amigos sigue siendo prioritario, el ocio digital domina. |
| *De ahí que* + subjuntivo | El ocio es digital; de ahí que las actividades culturales pierdan terreno. |
| *Dado que / puesto que* + indicativo | Dado que las pistas están deterioradas, propongo renovarlas. |
| Relativo con preposición | el servicio en el que confié; el contrato mediante el cual se acordó… |
| Pasiva refleja | Se fomentará el deporte. Se desprende de los datos que… |
| Enfática | Lo que más sorprende es… / Es en este punto donde… |
| *No solo… sino también* | No solo mejora la salud, sino también la convivencia. |
| Proporción | Cuanto más tiempo se pasa conectado, menos se sale a la calle. |
| Nominalización | El auge tecnológico ha transformado el ocio. (en vez de: la tecnología ha crecido y ha cambiado…) |
| Condicional de cortesía | Agradecería que me respondieran… |

## 7. Registro: de coloquial a formal

| Coloquial / plano | Formal |
|---|---|
| una gran apasionada de | aficionada a / muy interesada en |
| me gusta muchísimo | me atrae especialmente |
| hacer cosas | realizar actividades |
| mucha gente | una gran parte de la población |
| un montón de | un elevado número de |
| lo que pasa es que | ocurre que / cabe señalar que |
| no estoy de acuerdo | discrepo de / no comparto esta decisión |
| cambiar de compañía de inmediato | me plantearé cambiar de compañía / sin demora |

## 8. Plantillas por tipo de texto

**Párrafo argumentativo:** afirmación → causa → ejemplo o dato → consecuencia.

*Ejemplo:* Las pistas de tenis requieren una renovación urgente (afirmación), puesto que presentan un notable deterioro (causa); de hecho, muchas resultan inutilizables en invierno (dato). De ahí que el barrio carezca de espacios deportivos adecuados (consecuencia).

| Tipo de texto | Estructura |
|---|---|
| Análisis de datos | Introducción (tema + fuente) → dato principal → comparación → dato llamativo → interpretación → opinión → conclusión |
| Ensayo crítico | Tesis → argumento 1 (+ ejemplo) → argumento 2 → contraargumento + refutación → conclusión |
| Carta formal | Lugar y fecha → saludo → motivo → desarrollo → petición concreta (con plazo) → advertencia o propuesta → cierre → firma |

## 9. Errores recurrentes: reglas para memorizar

| Error | Corrección | Regla |
|---|---|---|
| depende por | depende **de** | Régimen: depender **de**, tratarse **de**, consistir **en**, contribuir **a** |
| en relación al | en relación **con** el | También: *con respecto a*, *respecto de* |
| conectados en Internet | conectados **a** Internet |  |
| a partir de proximo mes | a partir **del próximo** mes | Artículo + tilde |
| los jóvenes pasemos | los jóvenes **pasen** | La persona verbal sigue al sujeto real de la subordinada |
| Tambien, beneficiaran | También, beneficiarán | Las agudas acabadas en *-n, -s* o vocal y los futuros llevan tilde |
| tiempo libre**,** ha cambiado | tiempo libre ha cambiado | No se separa el sujeto del verbo con coma |

## 10. Hábitos de trabajo

| Hábito | Cómo hacerlo |
|---|---|
| Planificar | 5 minutos antes de escribir: esquema y 3 conectores que usar |
| Banco personal de léxico | Cada semana, 10 verbos o colocaciones nuevos, cada uno con una frase propia (no copiada) |
| Límite de repetición | Subrayar las palabras repetidas y sustituir al menos una por cada dos apariciones |
| Relectura: contenido | ¿Responde a todos los puntos del enunciado? ¿Argumenta, o solo enumera? |
| Relectura: gramática | Concordancias, subjuntivos, preposiciones |
| Relectura: ortografía | Tildes y puntuación |
| Reescritura | Rehacer un párrafo de cada texto aplicando solo estructuras de las secciones 4 y 6 |
| Presentación | Tachar con una sola línea y escribir la corrección sobre la palabra, no encima |
| Transferencia | Escribir la misma idea en tres registros (carta formal, ensayo, mensaje informal) |
